## Additional independent observations

1. The MDX does not distinguish inference memory from training memory or replicated state from sharded state before discussing splitting. This is a foundational discontinuity and is covered in CH0-03.
2. Several SVG/network diagrams use topology shapes that imply facts not present in the reference platform (for example, three leaf switches rather than eight rails). The remediation will either simplify them as clearly illustrative or align them with the selected reference architecture.
3. No central numeric constants exist. Repeated bandwidth values have already diverged across the chapter and visualizations. A small shared Chapter 0 constants/calculation module is justified to prevent future divergence.
4. Existing browser smoke tests hard-code image page indexes. If educational pagination changes, those tests must be made structural rather than relying on brittle absolute indexes, while still validating that all official images render.
5. Chapter 0 currently lacks any automated numerical regression coverage. Calculation functions should be deterministic and tested independently of the browser.
